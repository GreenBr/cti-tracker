ValleyRAT Delivered via Trojanized QN Wallpaper Installer

Unclear Confidence: Low

A malicious installer disguised as adware deployed a modified version of the Chinese desktop wallpaper management tool QN Wallpaper, which performed DLL sideloading and dropped a persistence file into the Startup folder to ultimately launch the ValleyRAT malware.
