GhostRedirector deploys Gamshen IIS module on compromised servers, mainly in Brazil

来自中国（归因于中国的攻击组织） 置信度: 中

ESET documented at least 65 Windows servers, mainly in Brazil, Thailand, and Vietnam, compromised by GhostRedirector, an actor assessed with medium confidence as China-aligned, which in June 2025 installed a malicious native IIS module called Gamshen. Gamshen altered server responses only when the request came from Googlebot, artificially promoting gambling websites in search results while leaving ordinary visitors unaffected.
