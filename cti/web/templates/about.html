{{ _("What this site is") }}

{{ _("An automatically updated tracker of cyber attack activity related to the People's Republic of China, in both directions: campaigns by China-attributed threat actors, and attacks against targets inside China. It is a personal research tool; nothing here is original attribution research.") }}

{{ _("How it works") }}

  1. {{ _("Fetch") }} — {{ _("the pipeline pulls the latest articles from public security sources (vendor research blogs, government advisories, security news) via RSS, in English and Chinese.") }}
  2. {{ _("Filter") }} — {{ _("articles are pre-screened by keywords: the names and aliases of China-attributed groups imported from MITRE ATT&CK, plus geographic terms. Matching articles become candidates.") }}
  3. {{ _("Extract") }} — {{ _("each candidate article is read by an LLM, which records every attack it describes in a fixed schema: actor, victim country and sector, date, direction, MITRE ATT&CK techniques, and a confidence level. Malformed answers are rejected, and irrelevant articles yield no incidents.") }}
  4. {{ _("Publish") }} — {{ _("the database is rendered into this static site in three languages. Every incident links back to the article it came from.") }}
